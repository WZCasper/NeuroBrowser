# NeuroBrowser
NeuroBrowser — мультисессионный десктопный браузер на Python (PyQt6 / Chromium) в стилистике Cyberpunk.  • Изолированные профили для мультиаккаунтинга • Плиточный режим (Grid Matrix) для параллельной работы • Умный сетевой AdBlocker (не ломает плееры) • Кнопка бесплатного просмотра на Кинопоиске • Экспресс-панель и мониторинг ресурсов CPU/RAM
